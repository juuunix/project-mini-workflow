# 모음보드 요금제 안내

- 문서 번호: CUS-001
- 상태: 현행
- 시행일: 2026-01-01

> 이 문서는 과제 시연을 위해 AI로 생성한 가상 회사의 문서입니다.

## 1. 개요

모음보드는 팀의 업무와 일정을 보드와 카드로 관리하는 협업 서비스이다. 이 문서는 2026년 1월 1일부터 적용되는 요금제 구성과 가격, 결제 방식을 안내한다. 모든 가격은 부가가치세 별도이다.

## 2. 요금제 구성

## 3. 요금제별 주요 기능

### 무료
- 기본 보드, 카드, 댓글 기능
- 최근 30일 활동 기록 조회

### 스탠다드
- 무료 요금제의 모든 기능
- 반복 카드, 일정 보기, 보드 템플릿
- 외부 연동 API v2 사용 (분당 300회)

### 프로
- 스탠다드 요금제의 모든 기능
- 권한 세분화, 게스트 초대, 감사 로그 조회
- 활동 기록 무제한 보관
- 외부 연동 API v2 사용 (분당 600회)

### 엔터프라이즈
- 프로 요금제의 모든 기능
- 단일 로그인(SSO), 전용 담당 매니저
- 서비스 수준 협약(SLA) 99.9% 보장
- 데이터 보관 지역 선택

## 4. 결제 방식

1. 결제 수단은 신용카드와 계좌 이체(연간 결제, 엔터프라이즈 한정)를 지원한다.
2. 월간 결제는 매월 가입일에 자동 결제되며, 연간 결제는 1년치를 한 번에 결제한다.
3. 연간 결제 시 월간 결제 대비 20% 할인된 가격이 적용된다.
4. 사용자 수가 늘어나면 추가 인원만큼 남은 기간에 대해 일할 계산하여 청구한다. 사용자 수를 줄이는 경우 다음 결제일부터 반영된다.

## 5. 요금제 변경

1. 상위 요금제로 변경하면 즉시 적용되며, 남은 기간의 차액을 일할 계산하여 청구한다.
2. 하위 요금제로 변경하면 현재 결제 주기가 끝난 다음 날부터 적용된다.
3. 하위 요금제의 한도(보드 개수, 저장 공간)를 넘는 데이터는 삭제되지 않지만, 한도 안으로 줄이기 전까지 새 항목을 만들 수 없다.

## 6. 무료 체험

스탠다드와 프로 요금제는 14일 무료 체험을 제공한다. 체험 기간이 끝나면 결제 수단을 등록하지 않은 워크스페이스는 무료 요금제로 자동 전환된다.

## 7. 문의

요금제 선택이나 견적 관련 문의는 고객지원팀 또는 영업 담당 부서로 접수한다. 환불 기준은 환불 정책(CUS-002)을 따른다.

## 8. 비영리 단체와 교육 기관 할인

1. 등록된 비영리 단체와 초·중·고등학교, 대학교는 스탠다드와 프로 요금제를 정가의 50%로 이용할 수 있다.
2. 할인을 받으려면 고유번호증 또는 기관 증빙 서류를 고객지원팀에 제출하고, 심사는 3영업일 안에 마친다.
3. 할인 자격은 1년마다 다시 확인하며, 자격을 잃으면 다음 결제일부터 정가를 적용한다.
