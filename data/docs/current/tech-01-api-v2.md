# 모음보드 외부 연동 API v2 가이드

- 문서 번호: TEC-001
- 상태: 현행
- 시행일: 2025-02-01

> 이 문서는 과제 시연을 위해 AI로 생성한 가상 회사의 문서입니다.

## 1. 개요

모음보드 외부 연동 API v2는 고객사가 자체 시스템에서 보드, 카드, 멤버 정보를 조회하고 변경할 수 있도록 제공하는 REST API이다. 모든 요청과 응답은 JSON 형식이며 문자 인코딩은 UTF-8이다.

- 기본 주소: `https://api.moeumboard.example/v2`
- 지원 프로토콜: HTTPS (TLS 1.2 이상)
- 담당 부서: 플랫폼운영팀

## 2. 인증

1. 고객사 관리자는 관리 콘솔의 "API 연동" 메뉴에서 클라이언트 ID와 클라이언트 시크릿을 발급받는다.
2. OAuth 2.0 클라이언트 자격 증명 방식으로 `/v2/oauth/token`에 요청해 액세스 토큰을 받는다.
3. 액세스 토큰의 유효 시간은 1시간이며, 만료 전에 재발급한다.
4. 모든 API 요청의 `Authorization` 헤더에 `Bearer {access_token}`을 포함한다.
5. 클라이언트 시크릿이 노출되면 즉시 관리 콘솔에서 폐기하고 재발급한다.

## 3. 주요 엔드포인트

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/v2/boards` | 보드 목록 조회 |
| GET | `/v2/boards/{board_id}` | 보드 상세 조회 |
| POST | `/v2/boards/{board_id}/cards` | 카드 생성 |
| PATCH | `/v2/cards/{card_id}` | 카드 수정 |
| DELETE | `/v2/cards/{card_id}` | 카드 삭제 |
| GET | `/v2/members` | 워크스페이스 멤버 조회 |
| POST | `/v2/webhooks` | 웹훅 등록 |

## 4. 페이지네이션

목록 조회 API는 커서 방식 페이지네이션을 사용한다. 응답의 `next_cursor` 값을 다음 요청의 `cursor` 파라미터로 전달한다. `limit`의 기본값은 50, 최댓값은 200이다. `next_cursor`가 `null`이면 마지막 페이지이다.

## 5. 호출 한도

| 요금제 | 분당 호출 한도 | 일일 호출 한도 |
| --- | --- | --- |
| 스탠다드 | 300회 | 100,000회 |
| 프로 | 600회 | 500,000회 |
| 엔터프라이즈 | 협의 | 협의 |

한도를 넘으면 HTTP 429 응답과 함께 `Retry-After` 헤더로 재시도 가능 시각(초)을 알려준다. 클라이언트는 지수 백오프로 재시도해야 한다.

## 6. 웹훅

1. 카드 생성·수정·삭제, 멤버 추가 이벤트를 웹훅으로 받을 수 있다.
2. 웹훅 요청에는 `X-Moeum-Signature` 헤더가 포함되며, 등록 시 발급된 서명 키로 HMAC-SHA256 검증을 해야 한다.
3. 수신 서버가 5초 안에 2xx로 응답하지 않으면 최대 5회까지 재전송한다.

## 7. 오류 응답

| HTTP 코드 | 오류 코드 | 의미 |
| --- | --- | --- |
| 400 | `invalid_request` | 요청 형식 오류 |
| 401 | `invalid_token` | 토큰 누락 또는 만료 |
| 403 | `forbidden` | 권한 없음 |
| 404 | `not_found` | 대상 리소스 없음 |
| 429 | `rate_limited` | 호출 한도 초과 |
| 500 | `internal_error` | 서버 내부 오류 |

오류 응답 본문에는 `error`, `message`, `request_id` 필드가 포함된다. 문의 시 `request_id`를 함께 전달하면 원인 확인이 빨라진다.

## 8. 변경 관리

API에 하위 호환되지 않는 변경이 생기면 최소 6개월 전에 개발자 공지 페이지와 관리자 이메일로 알린다. 필드 추가처럼 하위 호환되는 변경은 사전 공지 없이 반영될 수 있으므로, 클라이언트는 알 수 없는 필드를 무시하도록 구현한다.

## 9. 테스트 환경

연동을 개발하는 고객사는 운영 데이터에 영향을 주지 않도록 테스트 환경(`https://sandbox.moeumboard.example/v2`)을 먼저 사용한다. 테스트 환경의 데이터는 매주 일요일 새벽에 초기화되며, 호출 한도는 분당 60회로 고정된다. 테스트 환경용 클라이언트 자격 증명은 운영 환경과 따로 발급한다.
