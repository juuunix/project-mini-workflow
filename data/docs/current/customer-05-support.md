# 고객지원 운영 기준

- 문서 번호: CUS-005
- 상태: 현행
- 시행일: 2025-09-01

> 이 문서는 과제 시연을 위해 AI로 생성한 가상 회사의 문서입니다.

## 1. 목적

이 문서는 모음보드 고객 문의를 접수하고 처리할 때 고객지원팀이 지켜야 할 운영 시간, 응답 목표, 처리 절차를 정한다. 고객에게 공개되는 응답 목표의 근거 문서로도 사용한다.

## 2. 문의 채널

| 채널 | 이용 대상 | 운영 시간 |
| --- | --- | --- |
| 웹 문의 | 전 고객 | 접수 상시, 답변 평일 09:00~18:00 |
| 서비스 내 상담창 | 스탠다드 이상 | 평일 09:00~18:00 |
| 전화 상담 | 엔터프라이즈 | 평일 09:00~18:00 |
| 긴급 장애 접수 | 엔터프라이즈 | 연중무휴 24시간 |
| 커뮤니티 게시판 | 무료 요금제 | 상시 (고객 간 답변 중심) |

## 3. 응답 목표

| 요금제 | 첫 응답 목표 | 해결 목표 (일반 문의) |
| --- | --- | --- |
| 무료 | 보장하지 않음 | 보장하지 않음 |
| 스탠다드 | 1영업일 | 3영업일 |
| 프로 | 4시간 (영업시간 기준) | 2영업일 |
| 엔터프라이즈 | 1시간 | 1영업일 |

장애로 인한 문의는 요금제와 관계없이 장애 대응 절차의 고객 공지 기준을 함께 적용한다.

## 4. 문의 유형 분류

1. **결제·환불**: 결제 오류, 환불 요청, 세금계산서
2. **계정·접속**: 로그인 불가, 비밀번호, 단일 로그인 설정
3. **기능 사용**: 보드, 카드, 연동 기능 사용 방법
4. **오류 신고**: 기능 오작동, 데이터 표시 오류
5. **제안**: 기능 개선 요청

상담원은 접수 즉시 유형과 우선순위를 지정한다.

## 5. 처리 절차

1. 접수된 문의는 요금제와 유형에 따라 자동으로 담당 큐에 배정된다.
2. 상담원은 첫 응답에서 문의 내용을 확인하고 예상 처리 일정을 안내한다.
3. 기술 확인이 필요한 오류 신고는 재현 절차와 화면 정보를 정리해 개발 조직에 이관한다. 이관 후에도 고객 소통은 고객지원팀이 맡는다.
4. 해결 후 3영업일 동안 고객 회신이 없으면 문의를 종료하고 만족도 설문을 보낸다.

## 6. 본인 확인

계정 정보 변경, 데이터 내보내기, 환불 요청은 워크스페이스 관리자 본인임을 확인한 뒤 처리한다. 확인은 관리자 이메일로 발송한 확인 코드로 진행하며, 상담원은 비밀번호를 묻지 않는다.

## 7. 품질 관리

1. 고객지원팀 책임자는 매주 응답 목표 달성률과 만족도 점수를 점검한다.
2. 응답 목표 달성률이 2주 연속 90% 아래로 떨어지면 인력 배치와 자동 응답 문구를 재검토한다.
3. 자주 묻는 질문은 분기마다 이용 FAQ(CUS-003)에 반영한다.

## 8. 공휴일 운영

공휴일과 회사 휴무일에는 웹 문의 접수만 가능하며, 답변은 다음 영업일부터 순서대로 진행한다. 엔터프라이즈 긴급 장애 접수는 공휴일에도 운영한다.

## 9. 상담 기록 보관

상담 내용과 첨부 자료는 문의 종료 후 3년 동안 보관하며, 보관 기간이 지나면 자동으로 삭제한다. 고객이 요청하면 해당 워크스페이스의 상담 기록 사본을 제공할 수 있다. 상담원은 상담 기록에 결제 카드 번호 전체나 비밀번호를 적지 않는다.
