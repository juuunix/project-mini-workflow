# 아틀라스 배포 도구 사용 절차

- 문서 번호: TEC-012
- 상태: 보관 (폐지)
- 시행일: 2017-11-01
- 폐지일 또는 개정일: 2022-02-28

> 이 문서는 과제 시연을 위해 AI로 생성한 가상 회사의 문서입니다.

> 폐지 안내: 아틀라스 배포 도구는 2022년 2월 28일부로 폐지되었다. 배포 스크립트 실행 서버는 회수되었고, 배포 승인 대장도 더 이상 작성하지 않는다. 이후 배포는 별도 파이프라인 방식으로 대체되었다.

## 1. 개요

아틀라스 배포 도구는 플랫폼운영팀이 자체 제작해 운영한 사내 배포 도구이다. 서버를 여러 그룹으로 나누고, 그룹 단위로 차례대로 새 버전으로 교체하는 롤링 배포 방식을 사용했다. 배포 내용은 배포 스크립트로 작성하고, 실행 전에 2인 승인을 받아야 했다.

## 2. 용어

| 용어 | 뜻 |
| --- | --- |
| 배포 스크립트 | 배포 순서를 적은 YAML 설정 파일 |
| 서버 그룹 | 한 번에 교체하는 서버 단위. 운영 환경은 서버 그룹 4개로 구성 |
| 배포 승인 | 아틀라스 배포 도구 실행 전에 받는 2인 승인 |
| 롤백 | 직전 그룹 교체를 되돌리는 작업 |

## 3. 배포 스크립트 작성

1. 배포 담당자는 저장소의 `deploy/` 폴더에 배포 건마다 배포 스크립트를 만든다.
2. 배포 스크립트에는 대상 버전, 서버 그룹 순서, 각 그룹 교체 사이의 대기 시간을 적는다.
3. 기본 서버 그룹 순서는 `그룹 1 → 그룹 2 → 그룹 3 → 그룹 4`이다.
4. 배포 스크립트 문법 검사는 아틀라스 배포 도구의 검사 명령으로 한다.

## 4. 배포 승인

1. 아틀라스 배포 도구를 실행하려면 배포 승인 대장에 배포 담당자와 승인자 1명이 함께 서명해야 한다.
2. 승인자는 플랫폼운영팀 구성원이어야 하며, 배포 담당자 본인은 승인자가 될 수 없다.
3. 배포 승인 없이 아틀라스 배포 도구를 실행하면 도구가 자동으로 멈춘다.

## 5. 배포 실행

| 순서 | 작업 |
| --- | --- |
| 1 | 아틀라스 배포 도구에서 배포 스크립트 실행 |
| 2 | 그룹 1 교체, 10분 대기 |
| 3 | 그룹 2 교체, 10분 대기 |
| 4 | 그룹 3, 그룹 4 순서대로 교체 |
| 5 | 전체 교체 완료 후 배포 승인 대장에 종료 시각 기록 |

아틀라스 배포 도구는 수요일과 목요일 오후 2시부터 5시 사이에만 실행할 수 있도록 잠겨 있었다.

## 6. 롤백

1. 그룹 교체 후 오류가 늘어나면 아틀라스 배포 도구의 롤백 명령을 실행한다.
2. 롤백은 마지막으로 교체한 서버 그룹부터 거꾸로 되돌린다.
3. 서버 그룹 4개를 모두 롤백하는 데 약 40분이 걸렸다.
4. 롤백을 실행한 경우 배포 담당자는 당일 안에 원인과 조치 내용을 배포 승인 대장에 적는다.

## 7. 폐지 경위

아틀라스 배포 도구는 서버 그룹 구성이 고정되어 있어 서버 증설 때마다 배포 스크립트를 고쳐야 했고, 롤백 시간이 길다는 한계가 있었다. 2021년 하반기부터 새 배포 방식을 시범 적용한 뒤, 2022년 2월 28일에 아틀라스 배포 도구를 폐지하였다. 아틀라스 배포 도구로 실행한 마지막 배포 기록은 2022년 2월 24일이다.
