# 환불 정책 (2023년판)

- 문서 번호: CUS-002
- 상태: 보관 (개정 전)
- 시행일: 2023-01-01
- 폐지일 또는 개정일: 2025-12-31

> 이 문서는 과제 시연을 위해 AI로 생성한 가상 회사의 문서입니다.

> 보관 안내: 이 문서는 2026년 1월 1일 개정으로 효력을 잃은 이전 판이다. 환불 가능 기간, 위약금, 처리 기간이 현행과 다르다.

## 1. 목적

이 정책은 모음보드 유료 요금제의 결제 취소와 환불 기준을 안내한다.

## 2. 환불 기준

### 2.1 월간 결제

| 신청 시점 | 환불 금액 |
| --- | --- |
| 결제 후 3일 이내, 사용 이력 없음 | 결제 금액 전액 |
| 결제 후 3일 경과 또는 사용 이력 있음 | 환불 불가, 해당 결제 주기 종료 시 해지 |

### 2.2 연간 결제

| 신청 시점 | 환불 금액 |
| --- | --- |
| 결제 후 14일 이내 | 결제 금액 전액 |
| 결제 후 14일 경과 | 남은 개월 수에 해당하는 금액에서 위약금 20%를 공제한 금액 |

1. 남은 개월 수는 환불 신청일이 속한 달을 포함하지 않는다.
2. 연간 결제로 받은 할인 금액(정가 대비 15%)은 환불 시 차감한다. 즉, 사용한 개월 수는 월간 정가로 다시 계산한다.

## 3. 환불 신청 방법

1. 워크스페이스 관리자가 고객지원팀에 이메일로 환불을 신청한다.
2. 신청 시 워크스페이스 주소, 결제 일자, 환불 사유를 기재한다.
3. 관리 콘솔에서의 직접 신청 기능은 제공하지 않는다.

## 4. 처리 기간

1. 고객지원팀은 접수 후 5영업일 이내에 환불 가능 여부를 안내한다.
2. 환불은 승인 후 10영업일 이내에 원래 결제 수단으로 처리한다.

## 5. 환불이 제한되는 경우

- 이용약관 위반으로 이용이 정지된 경우
- 할인 프로모션으로 결제한 경우 (할인율과 관계없이 환불 불가)

## 6. 서비스 장애에 따른 보상

회사 귀책으로 월간 누적 장애 시간이 8시간을 넘는 경우, 해당 월 이용료의 5%를 다음 결제 시 할인한다.

## 7. 해지와 데이터

해지 시 데이터 보관 기간은 당시 이용약관을 따른다.

## 8. 연간 결제 환불 계산 예시

연간 결제 금액이 1,020,000원(월 정가 100,000원 기준 15% 할인)인 고객이 결제 4개월 차에 환불을 신청한 경우, 사용한 3개월을 월 정가로 다시 계산한 300,000원과 신청 달 이용료 100,000원을 먼저 뺀다. 남은 금액에서 위약금 20%를 공제한 금액을 환불한다. 이 계산 방식 때문에 환불 금액이 예상보다 적다는 문의가 많았다.

## 9. 환불 문의 처리 원칙

고객지원팀은 환불 이메일을 받은 순서대로 처리하였으며, 처리 상태는 접수, 검토, 승인, 완료의 네 단계로 관리하였다. 환불이 거절된 경우에는 거절 사유와 해당 조항을 함께 회신하고, 고객이 이의를 제기하면 고객지원팀 책임자가 다시 검토하였다.
