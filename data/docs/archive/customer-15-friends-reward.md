# 프렌즈 리워드 프로그램 안내

- 문서 번호: CUS-013
- 상태: 보관 (판매 종료)
- 시행일: 2021-04-01
- 폐지일 또는 개정일: 2023-09-30

> 이 문서는 과제 시연을 위해 AI로 생성한 가상 회사의 문서입니다.

> 종료 안내: 프렌즈 리워드 프로그램은 2023년 9월 30일부로 종료되었다. 추천 코드 신규 발급과 등급 산정은 이날 중단되었고, 이미 받은 적립금은 2023년 12월 31일까지 이용료 차감에 쓸 수 있었다.

## 1. 개요

프렌즈 리워드는 기존 고객이 다른 팀에게 모음보드를 추천하면 보상을 주는 고객 추천 프로그램이다. 추천하는 고객마다 고유한 추천 코드를 주고, 그 추천 코드로 새 워크스페이스가 유료 결제를 하면 추천한 고객에게 적립금을 지급했다. 추천 실적이 쌓이면 등급이 올라가 보상이 커진다.

## 2. 용어

| 용어 | 뜻 |
| --- | --- |
| 추천 코드 | 워크스페이스마다 하나씩 발급되는 8자리 코드 |
| 피추천 고객 | 추천 코드로 가입한 새 워크스페이스 |
| 적립금 | 보상 단위. 1원 단위로 이용료에서 차감 |
| 등급 | 누적 피추천 고객 수에 따른 4개 단계 |

## 3. 추천 코드 발급

1. 유료 요금제를 3개월 이상 이용한 워크스페이스 관리자는 관리 화면의 "프렌즈 리워드" 메뉴에서 추천 코드를 발급받는다.
2. 추천 코드는 워크스페이스당 1개이며, 바꿀 수 없다.
3. 추천 코드를 공개 게시판이나 광고에 대량으로 올리는 행위는 금지한다.

## 4. 적립금 지급

1. 피추천 고객이 첫 유료 결제를 마치고 30일이 지나면, 추천한 워크스페이스에 적립금을 지급한다.
2. 피추천 고객에게도 첫 결제 금액의 10%를 할인해 준다.
3. 피추천 고객이 30일 안에 환불하면 적립금을 지급하지 않는다.

## 5. 등급

| 등급 | 누적 피추천 고객 | 피추천 고객 1곳당 적립금 |
| --- | --- | --- |
| 일반 | 1곳 이상 | 10,000원 |
| 실버 | 5곳 이상 | 14,000원 |
| 골드 | 20곳 이상 | 18,000원 |
| 플래티넘 | 50곳 이상 | 25,000원 + 연간 감사 선물 |

등급은 매월 1일에 다시 산정하며, 한 번 오른 등급은 내려가지 않는다.

## 6. 적립금 사용

1. 프렌즈 리워드 적립금은 다음 결제 금액에서 자동으로 차감된다.
2. 한 번의 결제에서 차감할 수 있는 적립금은 결제 금액의 50%까지이다.
3. 적립금은 현금으로 돌려받을 수 없으며, 지급일로부터 1년이 지나면 소멸한다.

## 7. 부정 참여

같은 기관이 워크스페이스를 여러 개 만들어 자기 추천 코드로 가입한 경우, 해당 적립금을 회수하고 프렌즈 리워드 참여 자격을 정지한다.

## 8. 종료 경위

일부 고객이 추천 코드를 대량으로 퍼뜨려 적립금을 과도하게 받는 사례가 늘었고, 등급 산정 기준을 둘러싼 문의가 많았다. 회사는 2023년 9월 30일에 프렌즈 리워드 프로그램을 종료하였다. 종료 시점의 플래티넘 등급 고객에게는 마지막 연간 감사 선물을 발송하였다.
