# 헤르메스 API 연동 가이드

- 문서 번호: TEC-011
- 상태: 보관 (지원 종료)
- 시행일: 2018-04-01
- 폐지일 또는 개정일: 2024-03-31

> 이 문서는 과제 시연을 위해 AI로 생성한 가상 회사의 문서입니다.

> 지원 종료 안내: 헤르메스 API는 2024년 3월 31일부로 지원이 종료되었다. 이후 헤르메스 API 엔드포인트(`/v1/...`)로 들어오는 요청은 모두 거부되며, 발급된 API 키도 일괄 폐기되었다. 외부 연동이 필요한 고객사는 후속 API로 전환해야 한다.

## 1. 개요

헤르메스 API는 모음보드 초기에 제공한 1세대 외부 연동 API이다. 사내에서는 "헤르메스"라는 프로젝트 이름으로 불렸다. 요청은 폼 인코딩, 응답은 XML 또는 JSON 중 하나를 선택할 수 있었다.

- 기본 주소: `https://legacy-api.moeumboard.example/v1`
- 인증 수단: API 키와 세션 토큰
- 담당 부서: 당시 연동개발팀 (현재 해체)

## 2. API 키와 세션

1. 고객사 관리자는 관리 화면의 "헤르메스 API 연동" 메뉴에서 API 키를 발급받는다. API 키는 32자리 문자열이며 만료 기한이 없다.
2. API 키로 `/v1/session`을 호출하면 세션 토큰이 발급된다.
3. 세션 토큰은 마지막 호출로부터 20분 동안 유효하며, 모든 요청의 쿼리 문자열에 `session_token=...` 형태로 붙인다.
4. API 키 하나당 동시에 열 수 있는 세션은 5개까지이다.

## 3. 주요 엔드포인트

| 경로 | 방식 | 설명 |
| --- | --- | --- |
| `/v1/session` | POST | API 키로 세션 열기 |
| `/v1/board/list` | GET | 보드 목록 조회 (한 번에 최대 100건) |
| `/v1/card/get` | GET | 카드 1건 조회 |
| `/v1/card/save` | POST | 카드 생성 또는 수정 (`card_no`가 있으면 수정) |
| `/v1/card/delete` | POST | 카드 삭제 |
| `/v1/session/close` | POST | 세션 닫기 |

목록 조회는 `page_no`와 `page_size` 파라미터를 쓰는 페이지 번호 방식이었다.

## 4. 호출 한도

헤르메스 API는 호출량을 가중치로 셌다. 일반 조회 1회는 1, 카드 생성·수정·삭제 1회는 3으로 계산한다.

| 계약 유형 | 분당 호출 한도 (가중치 합계) |
| --- | --- |
| 기본 연동 | 120 |
| 확장 연동 | 600 |

호출 한도를 넘으면 응답 본문에 `<result>RATE_LIMIT</result>`가 담겨 오며, 1분 뒤 다시 호출해야 한다.

## 5. 콜백

1. 카드가 바뀌면 고객사가 등록한 주소로 헤르메스 API 콜백을 보낸다.
2. 콜백에는 서명이 없었고, API 키 앞 8자리를 `key_hint` 필드로 함께 보내 발신처를 확인하게 했다.
3. 콜백 수신 실패 시 재전송은 하지 않았다.

## 6. 결과 코드

| 결과 코드 | 의미 |
| --- | --- |
| `OK` | 정상 처리 |
| `SESSION_EXPIRED` | 세션 만료, 다시 열어야 함 |
| `INVALID_KEY` | API 키가 틀리거나 폐기됨 |
| `RATE_LIMIT` | 호출 한도 초과 |
| `NOT_FOUND` | 대상 보드나 카드 없음 |

## 7. 전환 기간 안내

1. 전환 기간 동안 헤르메스 API 응답 헤더에 지원 종료 예정일을 함께 담아 보냈다.
2. 고객지원팀은 헤르메스 API 호출 기록이 있는 고객사 관리자에게 분기마다 전환 안내 메일을 보냈다.
3. 종료 1개월 전부터는 매주 하루씩 헤르메스 API를 1시간 동안 일시 중단해 미전환 고객사가 영향을 미리 확인하도록 했다.

## 8. 지원 종료 경위

헤르메스 API는 API 키에 만료가 없고 세션 토큰이 주소에 노출되며 콜백에 서명이 없다는 보안 문제가 지적되었다. 회사는 2023년 4월에 헤르메스 API 지원 종료를 예고하고 1년의 전환 기간을 둔 뒤, 2024년 3월 31일에 헤르메스 API를 완전히 종료하였다. 종료 직전까지 헤르메스 API를 쓰던 고객사는 약 40곳이었다.
