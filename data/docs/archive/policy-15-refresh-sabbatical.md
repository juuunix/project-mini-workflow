# 리프레시 안식월 운영 규정

- 문서 번호: POL-013
- 상태: 보관 (폐지)
- 시행일: 2018-01-01
- 폐지일 또는 개정일: 2022-12-31

> 이 문서는 과제 시연을 위해 AI로 생성한 가상 회사의 문서입니다.

> 폐지 안내: 리프레시 안식월은 2022년 12월 31일부로 폐지되었다. 폐지일까지 사용 자격을 얻은 구성원은 2023년 12월 31일까지 리프레시 안식월을 쓸 수 있도록 경과 조치를 두었으며, 이후 남은 자격은 소멸하였다.

## 제1조 (목적)

리프레시 안식월은 오래 근무한 구성원이 일정 기간 업무에서 벗어나 재충전할 수 있도록 장기근속자에게 유급 휴식 기간을 부여하는 제도이다.

## 제2조 (용어)

| 용어 | 뜻 |
| --- | --- |
| 리프레시 안식월 | 근속 5년마다 부여하는 1개월 유급 휴식 |
| 단축 사용 | 리프레시 안식월 중 2주만 쓰고, 남은 2주는 연차휴가로 적립하는 방식 |
| 사용 자격 | 근속 기간을 채워 리프레시 안식월을 쓸 수 있는 상태 |
| 대상자 명부 | 인사팀이 관리하는 사용 자격 보유자 목록 |

## 제3조 (사용 자격)

1. 입사일을 기준으로 근속 5년, 10년, 15년을 채우면 리프레시 안식월 사용 자격을 1회 부여한다.
2. 사용 자격은 부여일로부터 2년 안에 사용해야 하며, 기한이 지나면 소멸한다.
3. 휴직 기간은 근속 기간에 넣지 않는다.

## 제4조 (사용 방법)

| 구분 | 휴식 기간 | 급여 |
| --- | --- | --- |
| 리프레시 안식월 | 연속 1개월 | 기본급 100% |
| 단축 사용 | 연속 2주 + 남은 2주는 연차휴가로 적립 | 기본급 100% |

1. 리프레시 안식월은 연속으로만 사용할 수 있으며 나누어 쓸 수 없다.
2. 사용 시작일 3개월 전까지 인사팀에 신청하고, 소속 본부장의 승인을 받는다.
3. 같은 팀에서 같은 기간에 리프레시 안식월을 쓰는 사람은 1명으로 제한한다.
4. 리프레시 안식월 앞뒤로 연차휴가를 붙여 쓸 수 있으나, 합계 기간은 6주를 넘을 수 없다.

## 제5조 (휴식 기간의 처우)

1. 리프레시 안식월 기간에는 업무 연락을 하지 않는 것을 원칙으로 한다.
2. 휴식 기간은 근속 기간에 포함하며, 연차휴가 산정에도 출근한 것으로 본다.
3. 리프레시 안식월을 마친 구성원에게는 재충전 활동비 300,000원을 지급한다.
4. 휴식 기간 동안의 업무는 팀장이 미리 대행자를 지정해 처리한다.

## 제6조 (대상자 명부 관리)

1. 인사팀은 매년 1월 대상자 명부를 갱신하고, 사용 자격을 얻은 구성원에게 개별 안내한다.
2. 사용 기한 6개월 전까지 신청하지 않은 대상자에게는 인사팀이 다시 안내한다.
3. 퇴사 시 사용하지 않은 리프레시 안식월은 보상하지 않는다.

## 제7조 (폐지 경위)

2022년 하반기 인사 제도 개편 과정에서 리프레시 안식월 사용률이 대상자의 25% 수준에 그치고, 같은 팀 동시 사용 제한 때문에 사용 시기를 정하기 어렵다는 의견이 많았다. 회사는 리프레시 안식월을 2022년 12월 31일부로 폐지하고, 장기근속 구성원 처우는 다른 방식으로 개편하였다. 폐지 시점에 사용 자격을 가진 구성원은 2023년 말까지 리프레시 안식월을 사용하거나 단축 사용할 수 있었다.
