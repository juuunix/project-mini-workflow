# Python 규칙

개발 환경은 Python 3.13과 uv를 사용한다. 저장소를 새로 내려받으면 다음 명령으로 검사 도구와 커밋 훅을 준비한다.

```text
uv sync --locked
uv run pre-commit install
```

커밋 시 Ruff 자동 수정, Ruff 포맷, ty 타입 검사 순서로 실행한다. 파일이 자동 수정되면 변경 내용을 확인하고 다시 스테이징한 뒤 커밋한다. 전체 검사는 `uv run pre-commit run --all-files`로 실행한다. 독립적인 실험과 의도적인 오류 예제가 있는 `experiments/`는 검사 대상에서 제외한다.

- 테스트의 기대값은 현재 코드의 동작을 그대로 따르지 않고, 요구사항을 기준으로 정한다.

- 코드 포맷과 기본 정적 검사는 Ruff를 사용하며, 프로젝트의 Ruff 설정을 따른다.
- `ruff format`으로 코드 형식을 맞추고, `ruff check`로 코드 오류와 규칙 위반을 확인한다.
- import 정렬은 Ruff의 `I` 규칙을 활성화해 관리한다.
- 함수, 변수, 모듈 이름은 `snake_case`, 클래스 이름은 `PascalCase`, 상수는 `UPPER_SNAKE_CASE`로 작성한다.
- 함수의 매개변수와 반환값에 타입 힌트를 작성하고, 누락 여부는 Ruff의 `ANN` 규칙으로 검사한다.
- 타입 불일치는 ty로 검사하며, 타입 힌트 누락과 타입 불일치는 자동 검사에서 실패로 처리한다.
- 이름은 역할과 의미가 드러나도록 작성한다.
- 주요 함수와 클래스는 인터페이스(이름, 매개변수, 반환 타입과 역할)를 먼저 정의한 뒤 구현한다.
- 함수명과 타입으로 드러나는 설명은 반복하지 않는다. 입력 제약, 예외, 부수 효과 등 사용에 필요한 추가 정보가 있을 때 docstring을 작성한다.
- 불필요한 주석은 지양하고, 이름과 코드 구조로 의도가 드러나도록 작성한다.
